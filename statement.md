# Problem Statement

## String Manipulation Tool

Develop a Python-based **String Manipulation Tool** that allows the user to perform different operations on a given string through a simple menu-driven program.

The program should provide the following operations:

1. Find the length of the string.
2. Convert the string into uppercase.
3. Convert the string into lowercase.
4. Reverse the string.
5. Count the occurrence of a character.
6. Count the number of words.
7. Replace a word with another word.
8. Exit the program.

The program should take a string as input from the user and allow multiple operations to be performed using a menu. It should display the result of each selected operation and handle invalid choices appropriately.

### Objective

The objective of this project is to understand and implement basic **Python string operations**, user input, conditional statements, loops, and built-in string functions.

### Technologies Used

- Python
- GitHub
- Markdown

### Expected Outcome

The program should provide an easy-to-use menu through which users can perform various string manipulation operations and view the results directly.
